MetricBridge

Architecture summary · updated 12 Sep 2026 · verified against the initial import commit

A deterministic semantic firewall between autonomous agents and data warehouses. An agent asks for a governed metric in structured form. MetricBridge compiles the SQL, enforces partition pruning and limits on the syntax tree, and answers a bad request with a machine-readable correction instead of a wrong number.

How it works

  • Three MCP tools: discover_metrics → get_metric_signature → query_metric. Agents never write SQL.
  • Whitelist catalog: a metric absent from the manifest cannot be queried.
  • Four gates: validate against contract → compile to parameterised SQL → re-parse and assert on the AST → cost / circuit breaker → execute.
  • Refusals teach: stable code, offending field, remediation, valid alternatives. All errors at once.
  • Deterministic: same request, same SQL, same number, on every engine.
